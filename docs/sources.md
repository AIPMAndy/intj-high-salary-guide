# 资料来源、适用边界与核验方法

**核查时间：2026-10-20。** 本项目侧重方法和通用工具，不提供未经验证的2026年城市实时岗位工资统计，也不承诺涨薪幅度。

## 一、谈薪与谈判

1. **哈佛大学职业发展中心** — [Evaluating and Negotiating Job Offers](https://careerservices.fas.harvard.edu/resources/gsas-evaluating-and-negotiating-job-offers/)。支持的原则：评估Offer时应考虑基本薪资、奖金、股权、工作条件和职业发展；不得捏造竞争Offer；部分行业和岗位薪酬灵活性有限。
2. **Harvard Law School Program on Negotiation** — [A Negotiation Preparation Checklist](https://www.pon.harvard.edu/daily/negotiation-skills-daily/negotiation-preparation-checklist/)。谈判前澄清目标、优势、限制、对方利益及BATNA。
3. **Harvard Law School Program on Negotiation** — [Negotiation Preparation Strategies](https://www.pon.harvard.edu/daily/business-negotiations/negotiation-preparation-strategies/)。BATNA是谈判失败后的最佳可执行选择；它可以帮助设置接受/拒绝条件。
4. **Harvard Law School Program on Negotiation** — [Power and Negotiation: Advice on First Offers](https://www.pon.harvard.edu/daily/batna/power-and-negotiation-advice-on-first-offers/)。报价锚定影响谈判，但报价策略需结合双方谈判力量，不能无脑报高。

**如何使用：** 本站建议先采集可比岗位样本、明确个人可举证贡献，再提出薪酬诉求。示例话术是编辑整理的模板，不等于上述资料逐字结论，也不保证任何个体谈判成功。

## 二、关于INTJ与MBTI

- **The Myers-Briggs Company** — [MBTI assessment FAQ](https://www.themyersbriggs.com/en-US/Explore-Solutions/MBTI?type=page)。明确表示MBTI不应被用于招聘和人员筛选，因为它衡量偏好而不是能力。
- **The Myers-Briggs Company** — [MBTI Facts](https://www.themyersbriggs.com/en-US/Support/MBTI-Facts?trk=article-ssr-frontend-pulse_little-text-block)。明确指出MBTI不用于预测个人工作表现和岗位筛选。

**编辑立场：** “INTJ”只是一种选题和自我反思入口。不能由某人自称INTJ推论其薪水、胜任力、职业道路或适宜岗位。

## 三、中国大陆劳动合同与薪资条款

- [《中华人民共和国劳动合同法（2012修正）》— 上海市人民政府转发](https://www.shanghai.gov.cn/rcjygj/20250606/658d064be68c46fc892530a8cde92258.html)。可用于核对劳动合同、试用期等基础制度。具体适用和劳动争议处理应依据最新法条、所在地规定及实际合同文件。
- 社保、公积金缴费基数、个税、竞业和奖金发放的具体规则会随地区、用工形式、合同和时间变化。本站**不计算税后收入**，也不作法律判断。

## 四、工资计算器的定义

网站提供两组简单比较：

- **保证年现金** = 税前固定月薪 × 保证发薪月数 + 额外无条件现金奖金。
- **情景年现金** = 保证年现金 + 用户填写的预估浮动奖金（只是可能情景，可能实际为零）。
- **两方案差额** = B保证年现金 − A保证年现金；当A大于0时显示相对A的百分比。

**不计入**：股权估值、投资收益、未到手签字费、缴税、社保公积金、福利、通勤、潜在停工风险与一次性成本。若第13薪有考核条件，应该归入浮动部分；如果签字费需要返还，必须单独核对。用户输入数据只在本机计算，不上传服务器。

## 五、真实世界验证

- 收入和招聘数据只能作为**当下、有样本、有限场景**的参考，不得将岗位发布价格外推为公司实际支付价格。
- 通过至少20条可比公开岗位以及5条交叉询问来**增加信息覆盖**，只是编辑性的最低行动建议，不代表统计抽样意义上的精度或置信度。
- 任何示例薪资和经验均为教学情景，**不构成作者或客户的真实涨薪战绩**。
- 不要把相关性写成因果性。是否真正提高薪资，应通过个人决策记录、合同和实际到款验证。
